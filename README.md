# WNL — Aventura gráfica

Aventura gráfica point-and-click original basada en el universo narrativo de WNL. Motor: **Godot 4** (exportación a web y móvil).

- **Este repositorio (`Sebasm2kuy/wnl`)** guarda el progreso del juego y será el punto de ejecución (web / GitHub Pages).
- **`Sebasm2kuy/novela`** conserva el material narrativo fuente de la adaptación.
- El proyecto **Místicas** (Art Test previo) está archivado y no forma parte de WNL.

## Estructura

```
AVENTURA GRAFICA/
├── INSTRUCCIONES_PARA_Z_AI.md          # Punto de entrada para Z.ai (documento vivo)
├── DIRECTRICES_TECNICAS_Y_ARTISTICAS.md # Motor, arquitectura, estilo
├── MAPA_FUNCIONAL_HABITACION_WNL.md     # Función del escenario e interacciones
├── PLANO_DISTRIBUCION_HABITACION_WNL.md       # Distribución v1 (referencia)
├── PLANO_DISTRIBUCION_HABITACION_WNL_v2.md    # Distribución v2 (PROPUESTA, pendiente de aprobación)
├── MAPA_VISUAL_HOTSPOTS_COLISIONES_WNL.svg    # Mapa técnico v1 (referencia)
├── MAPA_VISUAL_HOTSPOTS_COLISIONES_WNL_v2.svg # Mapa técnico v2 (PROPUESTA)
├── REVISION_VISUAL_IMAGEN_CONCEPTUAL_HABITACION_WNL.md
├── INVENTARIO_IDEAS_ADAPTABLES.md
├── Escenarios/                          # Arte conceptual
├── HISTORIAL_CHAT/                      # Registro de decisiones por iteración
└── scripts/                             # Validación de coordenadas del plano
```
